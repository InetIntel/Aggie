# KPI tracking

Admins can find this under Settings → KPI tracking.

It tracks new accounts, successful logins, incidents created, and alerts or social posts assigned to incidents or flagged investigate/ignore each day. The table also shows how many different users logged in that day.

Use the date filters to choose a range and export it as CSV. Dates use UTC, with the newest day first. Tracking starts when this version runs. It doesn't fill in past activity.

Repeating the same assignment or flag on a report counts once per day. Login totals count each successful login. Deleting a record or undoing an action doesn't remove it from the past totals.
